## Bolsa de Trabajo

Sistema de bolsa de trabajo desarrollado en Java.

## Requisitos

- Java JDK 8
- NetBeans 21 o inferior (el proyecto y las pruebas se realizaron principalmente con NetBeans 17)

## Ejecución

1. Descargar el archivo ZIP del proyecto o clonar el repositorio.
2. Abrir el proyecto en NetBeans.
3. Ejecutar la clase `BolsaDeTrabajo.java`.
4. Seleccionar el modo de ejecución:
   - Consola
   - Ventana

## Persistencia

Los datos se almacenan mediante archivos CSV ubicados en la carpeta `data`.
